# dao.jslab
REST client with intelligent caching 🦀⚡

- Web Workers and middleware support
- WebAssembly thread support
- datamaps.py integration

For a live demo, check out https://dao.jslab.dev/.

### Building
```bash
cargo build --release
```

### Start
```bash
cargo run
```
